# Demo CRM CSV data

These files contain fictional records with reserved `example.com` email addresses and sample US-style `555-01xx` phone numbers.

- Import `leads-demo.csv` from **Leads → Import CSV**.
- Import `customers-demo.csv` from **Customers & contacts → Import CSV**.

The rows demonstrate the CRM's supported lead stages, sources, deal forecasts, customer statuses, lifetime values, MRR, tags, and notes. Importing the files more than once will skip records with duplicate email addresses.

All sample deal and customer amounts are illustrative and use the workspace's selected reporting currency.
